# גרסאות קודמות וארכיון

תיקיות אלה הועברו מהשורש ב־17 בנובמבר 2026, ללא מחיקת קבצים.
הגרסה הנוכחית נמצאת ב־`../version3_sv` והבדיקות שלה ב־`../TB_design`.

| נתיב | תוכן |
| --- | --- |
| DESIGN, TEST_BUNCH, more_design | מימושי VHDL ובדיקות קודמים |
| version3 | גרסת Booth ב־VHDL |
| UVM | סקריפטי Python לווקטורים ובדיקות עבור מערך 4×4 |

| Photos RTL | תרשימים ותמונות RTL קודמים |
| Version | תיקיית גרסה היסטורית |
| Final-Project | עותק נוסף של המאגר, כולל היסטוריית Git משלו |
| README_original.md, README_TIMING.md | התיעוד הקודם |

הארכיון שומר על המבנה הפנימי המקורי; סקריפטים היסטוריים עשויים להניח את נתיבי העבודה הישנים.
