# Systolic Array – Final Project

הגרסה הנוכחית היא מימוש SystemVerilog בתיקיית `version3_sv`, עם הבדיקות בתיקיית `TB_design`.
הגרסה כוללת את בדיקות SystemVerilog מ־10 באוקטובר 2026 (`c388e58`) ואת עדכוני המימוש והדוחות מ־31 באוקטובר 2026 (`68611e6`).

## מבנה התיקייה

| תיקייה | תוכן |
| --- | --- |
| [version3_sv](version3_sv/) | הגרסה הנוכחית: RTL, סקריפטים, תוצאות סינתזה ומימוש פיזי |
| [TB_design](TB_design/) | בדיקות SystemVerilog לרכיבי הגרסה הנוכחית |
| [docs](docs/) | ספר הפרויקט ותיעוד להגשה |
| [old_versions](old_versions/) | גרסאות VHDL קודמות, ניסויים, תמונות והעותק הנוסף של המאגר |

שמות התיקיות והמבנה הפנימי של הגרסה הנוכחית נשמרו. קובצי המקור והבדיקות לא שונו במסגרת הסידור.
